              적용한 일정은 인터넷 없이도 열려요

              ⑥ 앱 · 홈 화면 아이콘, 알림, 오프라인 일정

              목업 메모: 휴대폰 세로 기준(가로 360px 전후)입니다. PC의 3단(대화·일정·지도)을 아래 탭바 4개로 나누고, '모인 정보'는 대화 화면 위쪽에 가로로 넘기는 칩으로 줄였습니다. 아직 비어 있는 정보(숙소)는 점선 칩과 입력창 아래 안내로 같은 아이콘을 씁니다.

              회원가입

              비밀번호 찾기

              기능별 아이콘 규칙

              1. 한 기능에는 한 아이콘만 씁니다. 메뉴, 칩, 안내 문구, 표, 모바일 탭바 어디서든 같은 그림입니다.
              2. 아이콘은 한 파일(SVG 묶음)에 모아 두고 이름(i-stay 등)으로 불러 씁니다. 새로 그리지 않습니다.
              3. 선 두께 1.8, 둥근 끝, 24×24 격자로 통일합니다. 색은 글자색을 따라가고, 상태색(비·휴무·추천)만 바꿉니다.
              4. 다른 기능처럼 보일 수 있는 그림은 쓰지 않습니다. 예: 일정(달력)과 휴무(달력+X)는 X 표시로만 구분합니다.

              목업 메모: 오른쪽 회색 글자가 코드에서 부르는 이름입니다. React 화면과 Django 템플릿이 같은 SVG 파일을 쓰면 두 화면의 아이콘이 어긋나지 않습니다.
